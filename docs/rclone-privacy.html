Privacy Policy — minecraft-oracle

This application is a personal-use tool that uses the Google Drive API solely to upload and manage backup archives of a private Minecraft server to the developer's own Google Drive account.

Data access is limited to files created or managed by this application. No data is shared with, sold to, or accessed by any third party. This is not a public product and is not offered to other users.
